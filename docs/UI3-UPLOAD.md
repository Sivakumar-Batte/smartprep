# Upload
1. Extract the ZIP.
2. Upload all contents to the repository root.
3. Commit: `Add SmartPrep UI Sprint 3 Focus Mode`.
4. Wait 2–5 minutes.
5. Open `https://sivakumar-batte.github.io/smartprep/focus.html`.
6. Validate before changing the homepage.

Optional: link `focus.html` from `app.html`. `ui3-shared.css` is provided for gradual styling of legacy pages; do not remove their functional JavaScript.
