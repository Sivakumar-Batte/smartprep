# Validation checklist
- [ ] Dashboard opens on desktop and phone.
- [ ] Sidebar opens and closes on smaller screens.
- [ ] All cards and buttons navigate to the correct existing page.
- [ ] Theme toggle survives refresh.
- [ ] Attempt, revision, error, and session values match local records.
- [ ] Empty data shows zero or “No activity yet”; no values are invented.
- [ ] Seven-day chart reflects attempts and revision results only.
- [ ] Bottom navigation appears on mobile.
- [ ] Cloud, Evidence, Practice, Revision, Queue, and Analytics links work.
