# Non-technical setup
1. In Supabase open SQL Editor → New query.
2. Copy all text from `supabase/sprint8_5_sync_upgrade.sql`, paste, and Run.
3. In Authentication → URL Configuration add `https://sivakumar-batte.github.io/smartprep/cloud.html` as another redirect URL.
4. Upload this package to the GitHub repository root and commit `Add Sprint 8.5 Supabase Cloud Sync`.
5. Open `/smartprep/cloud.html`.
6. Paste the Publishable key (never Secret/service-role key), then Save connection.
7. Create account, confirm the email, and sign in.
8. Export a local backup from Sprint 4.
9. Click Upload local data once. Check rows appear in Supabase.
10. Tick confirmation and use Safe two-way sync.
