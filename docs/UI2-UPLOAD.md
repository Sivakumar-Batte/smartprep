# Upload and rollout
1. Extract the ZIP.
2. Upload all contents to the GitHub repository root.
3. Commit: `Add SmartPrep UI Sprint 2 workspace`.
4. Wait 2–5 minutes and open `https://sivakumar-batte.github.io/smartprep/app.html`.
5. Validate every navigation link.
6. After approval, make `index.html` redirect to `app.html` only if you are comfortable moving Evidence to a secondary page. This package does not replace index.html.
