# SmartPrep V1 — Sprint 4 Personal Data Layer

This is an **update package** for the existing live Sprint 3 repository. It does not contain or replace `public/data`.

## Adds
- Browser-local attempts
- Error records created from incorrect attempts
- Manual revision scheduling and completion
- Study-session logging
- Per-concept personal summaries
- Personal JSON export/import
- Personal-data clearing with confirmation

## Privacy and durability
Personal data is stored in browser `localStorage`. It is not uploaded to GitHub. Clearing browser/site data can erase it, so export backups regularly.

## Upload
Upload all contents to the repository root, replacing `index.html`, `src/app.js`, and `src/styles.css`. Commit message: `Add SmartPrep Sprint 4 Personal Data Layer`.
