# SmartPrep V1 — Sprint 2 Evidence Layer

Static, local-first APPSC Group-II study-system foundation.

## Implemented
- Official-node and canonical-concept separation
- Taxonomy v1.1 browser
- Q1–90 frozen P/U ledger (no inferred text or answers)
- PYQ filtering and detail inspection
- Append-only provenance display
- Mapping-history display
- Concept lifecycle-ready data structures
- Referential and enum validation
- GitHub Pages deployment

## Run locally
Serve the repository root with any static HTTP server, e.g. `python -m http.server 8000`, then open `http://localhost:8000`.

## Evidence warning
Question text and final answers remain null where primary material has not been checked. Q91–150 are not included. Distribution and priority analysis are deliberately disabled.
